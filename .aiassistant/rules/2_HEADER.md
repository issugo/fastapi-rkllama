# Python file Header

Chaque fichier Python doit contenir un en-tête standard pour faciliter la compréhension et la maintenance du code. L'en-tête doit inclure les informations suivantes :

- Nom du fichier
- Description du role fonctionnel du fichier
- Historique des modifications (si applicable)

L'en-tête doit être placé en haut du fichier Python, avant toute autre instruction ou commentaire.
